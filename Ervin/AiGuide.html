Build a Local AI Agent

A complete guide to creating a private Data Analyst using Ollama, PHP, and MySQL.

Prerequisites | 1. Database | 2. Backend (PHP) | 3. Frontend (HTML) | 4. Running It

Project Overview

This project creates an "Agentic" AI. Unlike standard chatbots that just recite pre-written text, this agent can:

  • Understand natural language questions (e.g., "Summarize the errors in April").
  • Generate SQL code dynamically to query your specific MySQL database.
  • Analyze the results and summarize the numbers back to you in plain English.
Privacy First: This entire system runs on your local machine. Your data never leaves your computer or goes to a cloud API like OpenAI.

Prerequisites

Before writing code, ensure you have the following installed:

  • XAMPP: To run Apache (Web Server) and MySQL (Database). Download here.
  • Ollama: To run the AI model (Llama 3) locally. Download here.
Hardware Warning: Since the AI runs on your computer, you need at least 8GB of RAM (16GB recommended). If you have an NVIDIA GPU, Ollama can use it for faster responses.

Step 1: Setup Ollama

Once Ollama is installed, you need to download the "Brain" (the model). Open your terminal (Command Prompt or PowerShell) and run:

ollama run llama3

This will download about 4GB of data. Keep this terminal window open (or run Ollama in the background) while you develop.

Step 2: The Database (MySQL)

We need a database for the AI to analyze. We will create a table named abnormalities with some sample data.

  1. Open phpMyAdmin (usually at http://localhost/phpmyadmin).
  2. Create a new database named bot_database.
  3. Click the SQL tab and paste the following code:
-- Create the database
CREATE DATABASE IF NOT EXISTS bot_database;
USE bot_database;

-- Create the table for abnormalities
CREATE TABLE IF NOT EXISTS abnormalities (
    id INT AUTO_INCREMENT PRIMARY KEY,
    report_date DATE NOT NULL,
    abnormality_type VARCHAR(100) NOT NULL,
    severity INT NOT NULL,
    description TEXT
);

-- Insert sample data (April and May)

Step 3: The Backend Agent (PHP)

Create a file named agent.php in your htdocs folder (e.g., C:\xampp\htdocs\my_ai_agent\agent.php).

This script is the core of the application. It performs a loop:

  1. Receives your question.
  2. Asks Ollama to convert the question into a SQL query.
  3. Executes that SQL on MySQL.
  4. Sends the raw data back to Ollama to generate a human summary.
<?php
// agent.php
header('Content-Type: application/json');

// --- CONFIGURATION ---
// Ollama runs on localhost port 11434 by default
 $ollama_url = 'http://127.0.0.1:11434/v1/chat/completions';
 $model_name = 'llama3'; // Ensure you ran 'ollama run llama3' in your terminal

// Database Credentials (Update if needed)
 $db_host = 'localhost';
 $db_name = 'bot_database';
 $db_user = 'root';
 $db_pass = '';

// --- 1. CONNECT TO DATABASE ---
try {
    $pdo = new PDO("mysql:host=$db_host;dbname=$db_name;charset=utf8", $db_user, $db_pass);
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    echo json_encode(['answer' => 'Database connection failed: ' . $e->getMessage()]);
    exit;
}

// --- 2. GET USER INPUT ---
 $userQuestion = $_GET['q'] ?? '';
if (empty($userQuestion)) {
    echo json_encode(['answer' => 'Please ask a question.']);
    exit;
}

// --- 3. AGENT STEP 1: GENERATE SQL ---
// We tell the AI about the table structure so it writes correct SQL.
 $schema = "Table: abnormalities. Columns: id (INT), report_date (DATE), abnormality_type (VARCHAR), severity (INT), description (TEXT).";
 $systemPromptSQL = "You are a MySQL expert. You must ONLY write SELECT queries. Do NOT use DELETE, DROP, TRUNCATE, INSERT, or UPDATE. Return ONLY the raw SQL code. Do not include markdown backticks.";
 $userPromptSQL = "Schema: {$schema}\n\nConvert this question to SQL: {$userQuestion}";

 $sqlQuery = askOllama($systemPromptSQL, $userPromptSQL, $ollama_url, $model_name);

// Clean the SQL response (remove markdown if AI adds it)
 $sqlQuery = str_replace(['```sql', '```', '```SQL'], '', $sqlQuery);
 $sqlQuery = trim($sqlQuery);

// --- 4. AGENT STEP 2: EXECUTE SQL ---
 $dataRows = [];
try {
    $stmt = $pdo->query($sqlQuery);
    $dataRows = $stmt->fetchAll(PDO::FETCH_ASSOC);
} catch (PDOException $e) {
    echo json_encode(['answer' => "I attempted to analyze the data but made a syntax error in the SQL query. Please try rephrasing.\n\nGenerated SQL: " . $sqlQuery . "\n\nError: " . $e->getMessage()]);
    exit;
}

if (empty($dataRows)) {
    echo json_encode(['answer' => "I queried the database but found no records matching your criteria."]);
    exit;
}

// --- 5. AGENT STEP 3: SUMMARIZE DATA ---
// Send the raw JSON results back to AI to create a human-readable summary
 $systemPromptSummary = "You are a professional data analyst. Be concise, helpful, and professional.";
 $userPromptSummary = "User Question: {$userQuestion}\n\nDatabase Results (JSON):\n" . json_encode($dataRows) . "\n\nPlease provide a clear summary of this data.";

 $finalAnswer = askOllama($systemPromptSummary, $userPromptSummary, $ollama_url, $model_name);

echo json_encode(['answer' => $finalAnswer]);


// --- HELPER FUNCTION: COMMUNICATE WITH OLLAMA ---
function askOllama($systemMsg, $userMsg, $url, $model) {
    $data = [
        'model' => $model,
        'messages' => [
            ['role' => 'system', 'content' => $systemMsg],
            ['role' => 'user', 'content' => $userMsg]
        ],
        'stream' => false,
        'temperature' => 0.1 // Low temperature for deterministic logic
    ];

    $ch = curl_init($url);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
    curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
    
    // Local inference can be slow, so we increase timeout
    curl_setopt($ch, CURLOPT_TIMEOUT, 120); 

    $response = curl_exec($ch);
    
    if (curl_errno($ch)) {
        return "Error connecting to local AI (Ollama): " . curl_error($ch) . ". Make sure the Ollama app is running and you have downloaded the model.";
    }
    
    $resData = json_decode($response, true);
    curl_close($ch);

    if (isset($resData['choices'][0]['message']['content'])) {
        return $resData['choices'][0]['message']['content'];
    }
    
    return "AI did not return a valid response.";
}
?>

    <script>
        const API_ENDPOINT = 'agent.php';
        const chatContainer = document.getElementById('chatContainer');
        const userInput = document.getElementById('userInput');
        const sendBtn = document.getElementById('sendBtn');

        sendBtn.addEventListener('click', handleUserMessage);
        userInput.addEventListener('keypress', (e) => { if (e.key === 'Enter') handleUserMessage(); });

        async function handleUserMessage() {
            const text = userInput.value.trim();
            if (!text) return;

            addMessage('user', text);
            userInput.value = '';
            showTypingIndicator();

            try {
                const response = await fetch(`${API_ENDPOINT}?q=${encodeURIComponent(text)}`);
                const data = await response.json();
                removeTypingIndicator();
                if (data.answer) addMessage('bot', data.answer);
                else addMessage('bot', "No response from agent.");
            } catch (error) {
                removeTypingIndicator();
                addMessage('bot', "Error: Could not connect to agent.php. Ensure XAMPP is running.");
            }
        }

        function addMessage(sender, text) {
            const msgDiv = document.createElement('div');
            msgDiv.className = `message ${sender}`;
            const avatarHtml = sender === 'bot' ? '<div class="bot-avatar" style="width:30px; height:30px; font-size:0.8rem; flex-shrink:0;">AI</div>' : '';
            msgDiv.innerHTML = `${avatarHtml}<div class="bubble">${text}</div>`;
            chatContainer.appendChild(msgDiv);
            chatContainer.scrollTop = chatContainer.scrollHeight;
        }

        function showTypingIndicator() {
            const d = document.createElement('div');
            d.className = 'message bot typing-message'; d.id = 'typingIndicator';
            d.innerHTML = '<div class="bot-avatar" style="width:30px; height:30px; font-size:0.8rem;">AI</div><div class="bubble"><div class="typing-indicator"><div class="typing-dot"></div><div class="typing-dot"></div><div class="typing-dot"></div></div></div>';
            chatContainer.appendChild(d);
            chatContainer.scrollTop = chatContainer.scrollHeight;
        }

        function removeTypingIndicator() { const i = document.getElementById('typingIndicator'); if(i) i.remove(); }
    </script>

Step 5: Running the Application

To see your AI Agent in action, follow these steps:

  1. Start XAMPP Control Panel. Start the Apache and MySQL modules.
  2. Start Ollama. Ensure the application is running (or the terminal window is open).
  3. Open Browser. Navigate to http://localhost/my_ai_agent/ (or whichever folder name you used).
  4. Test it. Type: "Create a summary of the abnormality for the month of april".

The bot will pause for a few seconds (thinking), then generate SQL, run it, and provide you with a text summary.
